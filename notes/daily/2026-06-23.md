### 1. TOKENIZER-7 — number after an operator (no space) is silently dropped (45 min)

- **Repro first (by hand, before touching code):**
  ```
  python -c "from minidatabase.Tokenizer import Tokenizer; t=Tokenizer(); t.input='a>5'; t.scan(); print([x.type.name for x in t.tokens])"
  ```
  Today this prints `['IDENTIFIER','GT','EOF']` — the `5` is gone. `a > 5` (spaced) is correct.
- **Red-first test:** in `test_tokenizer.py`, assert `a>5` → `[IDENTIFIER, GT, NUMBER, EOF]`. Also add `id>1`, `x<10`, `p>=4.5` (no spaces). Run it — it must go **red** now. If it passes, your test is wrong.
- **Fix concept (you write it):** step `a>5` char-by-char through `scan()`. The post-operator path advances past the next char before `number()` gets a chance to start on a digit. `number()` is likely only entered when a digit is the *first* char of a fresh lexeme. Find where the index over-advances after emitting the operator token.
- **Done-bar:** the red test goes green; full suite still green; re-run the by-hand repro and eyeball the tokens.

### 2. PARSER-11 — `parse()` silently swallows trailing tokens (45 min)

- **Repro first:**
  ```
  python -c "from minidatabase import parse; print(parse('SELECT * FROM users blah blah WHERE a > 5').where)"
  ```
  Today this prints `None` — the WHERE is silently dropped because parsing stops at the second identifier and never errors.
- **Red-first test:** assert `parse('SELECT * FROM users x y z')` **raises** `ParseError` (use `pytest.raises`, match on a position-bearing message). Run it — red now (it currently returns silently).
- **Fix concept (you write it):** at the end of `parse()`, after building the statement, `consume(TokenType.EOF)` / assert `peek().type == EOF`, else raise `ParseError` with source position. One guard.
- **Watch for:** this guard may expose *other* inputs that were silently passing on trailing garbage. That's the point — if a previously-green test now goes red, it was a lying test; fix the input or the assertion, don't weaken the guard.
- **Done-bar:** the raise-test goes green; full suite green; re-run the repro and confirm it now errors with a position.
