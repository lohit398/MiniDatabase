## The two lessons worth keeping

1. **The grammar IS the code.** Broke through the actual conceptual wall: in hand-written recursive descent there is no grammar object the program reads — each grammar rule becomes one method, the rule's order becomes the order of statements, the cursor carries position from one step to the next. A comparison is three sequential steps, not a loop. (The earlier `while`/`arr` scan was the stack/postfix mindset leaking back in — killed it.) Precedence/nesting (`(x*y)=5/10`) = a fixed ladder of one-method-per-precedence-level, each calling the next-tighter. That's day 6, not today.

2. **A green suite can lie.** Suite said 9/9 while the WHERE feature was completely broken — because no test exercised the new code. A throwaway probe (`Parser(tokens).parse()` + print) caught it instantly; `consume` was missing in `parseOperand` so the cursor never advanced. New reflex: new feature → probe it by hand → *then* trust green → *then* lock it with a test.
